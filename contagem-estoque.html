💾 Salvar / continuar contagem

Salve o que já foi bipado sem zerar a contagem. O salvamento no Google é um rascunho em abas separadas: não altera DANFEs, preços oficiais, saldos nem registros do PDV.
Os registros já bipados permanecem no navegador. Para gravar no Google, configure a integração.

Esta integração usa um Apps Script próprio para o estoque. O endereço e a chave ficam guardados somente neste navegador, nunca no GitHub. É preciso implantar o código do Apps Script de contagem antes de conectar.

Se o Google ainda não estiver conectado, “Salvar contagem” confirma o rascunho local; para ter outra cópia, use também “Exportar conferência CSV”. “Nova contagem” continua sendo a ação de zerar.
